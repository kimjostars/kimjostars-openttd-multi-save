# kimjostars-openttd-multi-save
본 웹페이지는 라은랜드에서 진행하는 오픈트타의 서버중 하나인 조별스서버의 연도별 세이브본을 저장 배포하기위한 웹사이트입니다.

## 실행 방법

Python 3.10 이상이 필요합니다. 별도 패키지 설치 없이 아래 명령으로 웹 페이지와 백엔드를 함께 실행합니다.

```bash
python3 server.py
```

브라우저에서 `http://127.0.0.1:8000`을 엽니다. 첫 이용자는 화면의 회원가입 메뉴에서 계정을 만들 수 있습니다. 로그인한 사용자만 폴더 생성과 `.sav` 파일 업로드를 할 수 있습니다.

메인 페이지에서 개인 보관함과 공동 보관함을 선택할 수 있습니다. 개인 보관함은 로그인한 계정의 파일만 보여주며, 공동 보관함의 폴더와 파일은 모든 방문자에게 공개됩니다.

계정과 폴더 정보는 `data/archive.sqlite3`, 업로드 파일은 `data/uploads/`에 저장됩니다. 이 경로는 Git에 포함되지 않습니다. 업로드 요청 하나의 최대 크기는 200 MiB입니다.

다른 기기에서 사용하려면 서버가 실행되는 컴퓨터의 네트워크 주소로 접속할 수 있어야 합니다. 기본 설정은 현재 컴퓨터에서만 접속 가능하도록 `127.0.0.1`에 바인딩합니다. LAN에서 시험할 때는 `python3 server.py --host 0.0.0.0`로 실행하고 방화벽에서 포트를 허용한 뒤 서버 컴퓨터의 내부 IP 주소로 접속하세요. 인터넷에 공개하기 전에는 HTTPS, 요청 제한, 스팸 방지 등을 갖춘 배포 환경을 구성해야 합니다.
